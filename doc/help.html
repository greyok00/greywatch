greywatch: the guide

greywatch is one dashboard for every tool that protects this Linux computer. This page walks each screen, shows the real app, and answers the questions people ask first. Where to start: the Security screen — it is the health table for everything below.

1. Wizard — guided setup

What it shows: the start of the setup wizard, which asks a few plain questions and then makes one real change at a time — preview first, apply only on your press, and every change is recorded so it can be undone.

The question this answers: “How do I make my first change without touching a terminal?” — Answer the wizard's questions and press Apply on the preview you like; press Cancel and nothing changes.

2. Security — the health table

What it shows: every protection on the machine as one row — a colored dot (green running, amber paused-by-you or waiting, red not running), the protection's name, its state in words, and its last activity. Pause and Resume buttons sit on each row. The crop below is that table close up.

The question this answers: “Is everything that should be running actually running?” — Read the dot and the word on each row; a red row is a protection that should be up but is not.

3. Tools — cards, scans, live progress

What it shows: the same protections as cards with a pause/resume control and an honest one-line state under each, a strip of quick-scan buttons with a live progress circle, and a short "Recent" log of what happened. The screenshot is the machine's real state while running: the auto-responder paused-by-you, most watchers running, the antivirus engine not running until you start it or its daily schedule fires.

The question this answers: “How do I run a scan right now?” — Press a quick-scan button on the strip and watch the circle; the scheduled scanners also run on their own timers without you.

4. Harden — baseline checks, apply, undo

What it shows: the harden flow: run baseline checks that test this computer's settings, review the result cards, and apply only what you approve through the system's privilege prompt. The Undo last change button reverts the latest applied change. The screenshot is a fresh session that has not run checks yet — the page says so in one line.

The question this answers: “How do I apply (or take back) a system setting safely?” — Run the checks, read the cards, apply what you agree with; Undo last change reverts the newest one.

5. Settings — the look, trusted items, update lists

What it shows: the app's own controls: the theme picker (Dark Mode / Light Mode, changes instantly and is remembered), your trusted-list entries, and where the update lists (virus definitions, CVE list) stand. The crop is the theme picker itself.

The question this answers: “How do I change the theme?” — On Settings, pick Dark Mode or Light Mode under "Look of the app"; it applies instantly and sticks across restarts.

6. Logs — the raw record

What it shows: every tool's raw event record, newest first, with identical consecutive lines grouped and a filter for one tool at a time. In this capture the body is empty because the desktop's event store is written by the root daemon with owner-only permissions; run the same view as root, or read events through the app's own account, to see rows.

The question this answers: “Where is the raw record behind the friendly words?” — Logs keeps each tool's events one row per line; filter the combo to a single tool to see only its rows.

7. Help — this guide, in the app

What it shows: the in-app Help tab: how to use the app in one short list, an FAQ for the confusing moments, and one-sentence cards for every tool so you can tell an "auto-responder" from a "program jail" without a manual.

The question this answers: “What does each protection actually do?” — The "Every tool, one sentence each" cards say it in plain words, and the FAQ below covers the moments that confuse people.

FAQ — the questions people ask

1. What does greywatch do?

It puts every protection already on this machine under one plain-English dashboard: live states, scans, guided changes, and an honest record. It does not install replacements for your tools — it points them and reports.

2. How do I run a scan?

Tools screen → press a quick-scan button and watch the progress circle. The scheduled scanners (live, temp-folder, antivirus full scan) also run on their own timers without you.

3. How do I pause a protection?

Security screen → press Pause on its row; the button becomes Resume. Protections managed by a service pause for real; auditors without a service say so in a note instead.

4. What does "At risk" mean?

A protection that should be running is not — for example a red "not running" antivirus. It names a gap in coverage; it does not mean something bad was found.

5. A detection appeared — what now?

Read the Recent line or the Logs row to see which tool flagged what. If you did not cause it, prefer the quarantine choice when the app offers one, and use Undo if you change your mind.

6. How do I isolate my machine?

There is no one-click panic button. Keep the firewall on, use the site wizard to cut off a specific bad site, and for a full disconnect turn off Wi-Fi or unplug the network.

7. How do I change the theme?

Settings → "Look of the app" → Dark Mode or Light Mode. The change is instant and remembered across restarts.

8. Why is my antivirus quiet?

It runs its full scan on a daily schedule, and quiet means nothing was found and nothing failed. Its last run and definition date sit on the Health rows on Security.

9. Is my disk encrypted — how do I check?

Today's baseline checks do not test disk encryption. In a terminal run lsblk -o NAME,FSTYPE; an encrypted disk shows crypto_luks.

10. How do I undo a change the wizard made?

Harden screen → press "Undo last change"; it reverts the latest applied change through the same privilege helper. The verification strip under it confirms what changed back.
